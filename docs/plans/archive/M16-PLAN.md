# M16 · 日期与日历

状态：已归档（2026-11-26）
目标：统一日期入口、补齐日历的跳转/跨日/拖选体验，让日历任务栏与任务 Tab 一致，并落地清单级已完成模式与重复任务自动补日期。

## 范围

本迭代只做以下反馈项；#11 重复完成提示、#24 逾期语义按用户决定暂不处理（等待专题调研）。

| 项 | 内容 |
|---|---|
| #8 | 共享 `V2DatePicker`：详情、日历等所有日期入口统一；圆角、可清空、可切换月份 |
| #19 | 任务详情日期入口接入新 picker，保留今天/明天/下周快捷 |
| #18 | 日历顶部可跳转日期，切换月份/周/日视图 |
| #30 | 跨日任务在月/周/日视图正确跨列切段 |
| #31 | 周/日视图拖选时间范围，选区高亮，松手后气泡输入创建任务 |
| #32 | 日历右侧任务栏支持分组（按清单/按分组）与排序（日期/优先级/创建时间/自定义）；点击任务与任务 Tab 打开同一详情 |
| #6 | 清单级“已完成显示”4 模式：已完成清单 / 原地划线 / 分组内置底 / 不显示；默认“分组内置底” |
| #12 | 设置重复规则且任务无日期时，自动补最近一次符合规则的日期 |

## 关键决策

- #6 默认 `group-bottom`（用户确认）；模式按清单存 `localStorage['lifeos.v2.listCompletedMode']`，虚拟视图用默认值；不新增 schema 字段。
- #12 只补“本来没有日期”的任务；daily=今天，weekly=最近目标星期几（含今天），monthly=本月该日/下月同日并按月末截断。
- 跨日任务以 `scheduledStartAt`/`scheduledEndAt` 的本地日期范围为准，按天切段，不改 Host 数据模型。
- 未排期任务仍进右侧任务栏与“未排期”区；不在月网格伪造时间。
- 拖选创建复用现有创建接口（POST /tasks），不引入新的批量端点。
